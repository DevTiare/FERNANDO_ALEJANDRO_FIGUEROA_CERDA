# 🚜 Página Web & Currículum Profesional — Fernando Alejandro Figueroa Cerda

Este repositorio contiene la página web de currículum vitae profesional para **Fernando Alejandro Figueroa Cerda** (Jefe de Bodega & Operador de Grúa Horquilla con Licencia Clase D), diseñada con HTML5, Tailwind CSS y JavaScript en una **gama de colores café y tierra elegante**, optimizada para **GitHub Pages** (costo $0).

---

## 🌟 Características Destacadas

- **Diseño en Gama de Colores Café**: Paleta de tonos crema, beige tostado y café espresso (`#FAF6F0`, `#F4EBE1`, `#3E2723`, `#8B4513`).
- **Perfil 2 en 1 (Operación & Gestión)**: Resalta más de 10 años de experiencia en grúa horquilla, liderazgo de bodegas, cuadratura de inventario físico vs. digital y cumplimiento de normas de seguridad.
- **Descarga Directa de CV (PDF)**: Botón que descarga el archivo PDF oficial `curriculum_vitae_Fernando_Figueroa.pdf`.
- **Formulario de Contacto Directo**: Preparado para integrarse con Web3Forms.

## 🚀 Cómo Publicar en GitHub Pages

1. Abre tu consola dentro de la carpeta `fernandogratis`:
   ```bash
   git init
   git add .
   git commit -m "Sitio Web Fernando Figueroa Cerda - Gama Cafe"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/fernandogratis.git
   git push -u origin main
   ```
2. Ve a GitHub -> **Settings** -> **Pages**.
3. En **Branch**, selecciona `main` y la carpeta `/ (root)`, luego presiona **Save**.

¡En 1 minuto la página estará activa públicamente!
👉 `https://TU-USUARIO.github.io/fernandogratis/`
